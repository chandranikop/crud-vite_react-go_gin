# Simple CRUD App (Vite React + Go Gin)

## About the Application
This application is a simple Create, Read, Update, Delete (CRUD) system for user data management, built with a modern web approach. The application is separated into two main pillars:
- **Backend (API Server)**: Built with the Go (Golang) programming language using the lightweight and fast Gin HTTP web framework. The backend handles routing and data logic management.
- **Frontend (User Interface/UI)**: Built using React (JavaScript Library) bundled with Vite, and styled with the TailwindCSS utility CSS framework, making the interface fast and interactive in *real-time*.

## Architecture and Folder Structure

This project uses a *Client-Server* separation architecture (Monorepo), where the Frontend and Backend code are stored separately in their respective directories and will run on different *ports* or *services* during development.

The essential folder structure of this application is as follows:
```text
crud-vite-go/
│
├── backend/                  # API/Server code folder (Golang)
│   ├── main.go               # Entry point, Gin router, CRUD controllers, & in-memory database storage
│   ├── go.mod                # Go module definition & dependency tracking file
│   └── go.sum                # Go dependency verification checksum
│
└── frontend/                 # Web client application folder (React)
    ├── src/
    │   ├── App.jsx           # Root React component, holds input form & data list
    │   ├── main.jsx          # Entry point that renders the React component to the HTML DOM
    │   └── index.css         # Default TailwindCSS configuration and custom styles
    ├── public/               # Publicly accessible static files
    ├── package.json          # Node.js library/package management and NPM scripts file
    ├── eslint.config.js      # Linter settings for code quality (ESLint)
    └── vite.config.js        # Vite development/build server configuration file
```

## Database Schema

Currently, the application does not use an external *database engine* (such as MySQL, PostgreSQL, or MongoDB). It uses **In-Memory Storage** simulation for simplicity. (*Note: Data will be reset every time the backend is restarted.*)

The `User` entity schema is defined as a *Struct* (in `main.go`) with the following fields:

| Field | Data Type | Description |
|-------|-----------|-------------|
| `ID` | `string` | Unique ID using UUID (Automatically generated by the backend system) |
| `Name` | `string` | User's name |
| `Email` | `string` | User's email address |

*Technical Note:* For the database simulation, the backend uses `[]User` (a Go slice) and `sync.Mutex` to ensure no *race conditions* occur if there are simultaneous data modification requests (*Concurrency safe*).

## Project Setup (Installation)

Before running the app, make sure your computer has the following prerequisites installed:
- **Node.js** (and NPM)
- **Golang** active version (version 1.20+)

Follow the steps below:

**1. Backend Environment Setup:**
Open a terminal and navigate to the backend folder, then download the required libraries.
```bash
cd backend
go mod download
```

**2. Frontend Environment Setup:**
Open a terminal and navigate to the frontend folder, then do the same to install Node packages.
```bash
cd frontend
npm install
```

## How to Run the Application

Since the application is separated, you need to open two terminals and run each service independently.

**Step 1: Start the Backend Server**
Open a terminal at your project root, then navigate into the backend folder:
```bash
cd backend
go run main.go
```
*The backend will run and serve the API on the default port `http://localhost:8080`.*

**Step 2: Start the Frontend UI**
Open a new terminal window (or tab), then go to the frontend folder:
```bash
cd frontend
npm run dev
```
*The Vite server will start. You can see the link provided in the terminal or open it directly in your browser at `http://localhost:5173` (port may differ — follow the console instructions).*

## How to Test the Application

**A. Manual Testing via the User Interface (Browser GUI):**
1. Open `http://localhost:5173` in your browser.
2. **CREATE**: Fill in the Name and Email input boxes, then press the Submit button — the new entry should appear in the list below.
3. **UPDATE**: Click the "Edit" button to update an existing entry.
4. **DELETE**: Pressing the Delete button will immediately remove the listed item.

**B. Endpoint Testing via API Client (e.g., cURL/Postman):**
Since the API is not protected by Auth/Tokens, it is very easy to test the raw API at `http://localhost:8080/users`:
1. Read/List Data:
   `GET` http://localhost:8080/users
2. Add a New User (requires JSON body):
   `POST` http://localhost:8080/users
   ```json
   {
       "name": "Alex",
       "email": "alex@mail.com"
   }
   ```
3. Update Data:
   `PUT` http://localhost:8080/users/<INSERT_ID>
4. Delete Data:
   `DELETE` http://localhost:8080/users/<INSERT_ID>
